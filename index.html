About Me

I'm in my first semester of Computer Science at Vedam School of Technology. Before college started I spent the summer as a Python intern at NXtutors, an education company in Gurugram, working on their live websites. I also co-built and run the online shops in my family's e-commerce business.

I use AI tools a lot, and I say so openly. That doesn't mean I don't know what I'm doing: I read and understand what the AI writes, and I decide whether it's the right change. What I'd claim as my own skill is checking the work: backing things up before changing them, testing a change before it goes live, and making sure something actually worked instead of trusting a tool that says it did.

LEVEL06

Learning at Vedam

What I've learnt at Vedam so far, month by month.

November 2026

Real JavaScript: functions, objects, the DOM and event listeners

Web Development: functions with parameters and return values, falsy values, why 5 / 2 is 2.5 in JavaScript, taking input with prompt() and turning it into a number, strings and template literals, string methods (trim, charAt, split, join), objects with dot and bracket access, for...in, nested objects and methods, and on 13 November the document object: finding an element with querySelector and changing its text or style from JavaScript. I wrote the functions lesson myself in class on 2 November. Lab: the terminal (ls, cd, mkdir, touch, code .), the defer keyword, and an object that stores what the user typed, with methods and the keyword this. Then (16 and 20 November) the DOM as a tree: creating an element with createElement, filling it and attaching it with appendChild, and the event-listener pattern (element, event, function): click, mouseenter, mouseleave, right-click, keydown and input events, the event object (e.target.value, e.key) and preventDefault. Lab (18 and 19 November): how JavaScript runs (the engine, just-in-time compilation, one thread and the event loop), var vs let vs const, finding elements with getElementById, and a working calculator that reads two inputs with .value and Number() when a button is clicked. I wrote a quiz creator in class on 20 November: it builds a question card from the form and lets you delete it again. Java: linear and binary search, finding the floor of a number in a sorted array, characters and ASCII (toggling case), strings (reversing, palindromes, substrings), string equality and StringBuilder: removing consecutive characters and compressing a string. Then (16 to 20 November) the stack (valid parentheses, popping the middle element), the queue, HashMap and HashSet (first non-repeating character, distinct elements, pairs that sum to K). Java lab: arrays and ArrayList.

October 2026

Flexbox, animation, Git and the first JavaScript

Web Development: positioning, z-index, flexbox and media queries (this page's layout), then transform, transition and animation, and Git and GitHub for working in a team: cloning, branches, pull requests, merging, forking, fixing merge conflicts, undoing commits and putting a site live with GitHub Pages. Lab: the portfolio layout, with object-fit so photos never stretch, then a navbar that stays at the top with a frosted-glass blur, buttons that lift when you hover, and flex-shrink so a photo keeps its size, then (29 October) a hero that appears one piece at a time using animation-delay, and skill bars that grow from zero with @keyframes. First JavaScript lesson (30 October): adding a script to a page, variables with let, console.log, if/else, for and while loops and arrays. I wrote FizzBuzz and a prime-number check in class. Java: ArrayList, 2D arrays and matrices (rotating, adding, subtracting and multiplying them), sorting with Arrays.sort and problems it unlocks: the cheapest order to remove array elements, counting "good" elements and wiggle sort. Java lab: star patterns.

September 2026

CSS and Java basics

Web Development: forms, tables, Git, CSS selectors, colours, the box model and CSS variables. Java: conditionals, loops, patterns, functions, time complexity and arrays.

August 2026

Starting out

Started Computer Science at Vedam School of Technology. First HTML pages (tags, links and page structure) and first Java programs (output, variables and input).
